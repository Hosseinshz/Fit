# الهام فیت

برنامه‌ساز تمرین فارسی: مربی برنامه را می‌سازد، شاگرد ست‌ها را تیک می‌زند، تایمر استراحت و ویدیوی حرکت را در باشگاه می‌بیند.

## آدرس زنده

GitHub خودِ فایل را به‌صورت سایت اجرا نمی‌کند. نسخهٔ قابل‌باز شدن:

**https://hosseinshz.github.io/Fit/**

اگر Pages هنوز فعال نشده باشد، از Settings → Pages → Deploy from branch `main` / `/` روشن شود.

فایل اصلی: [`index.html`](./index.html)

## استفاده

1. صفحه را در موبایل یا دسکتاپ باز کن.
2. برنامه را بساز یا برنامهٔ نمونه را باز کن.
3. خروجی HTML / لینک / PDF بگیر و برای شاگرد بفرست.
4. روی آیفون Safari → Share → Add to Home Screen.

داده‌ها روی خود دستگاه در `localStorage` می‌مانند؛ رمز یا حساب ابری ندارد.
